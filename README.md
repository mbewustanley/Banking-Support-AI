# Banking Support AI Platform

## Overview

A production-oriented GenAI application for answering banking
support questions using retrieved policy documents and controlled
AI workflows.

## Objectives

- Build a retrieval-augmented generation (RAG) pipeline.
- Use LangChain for LLM integration and retrieval.
- Use LangGraph for stateful orchestration.
- Evaluate retrieval quality and answer groundedness.
- Expose functionality through an API.
- Add testing, observability, and deployment practices.

## Security

- API keys are stored outside source control.
- Initial testing uses synthetic questions and policy documents.
- Generated answers must not be treated as authoritative financial advice.
